# Code of Conduct

Lighten follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, focus on the work, and make it easy for newcomers to take part.
Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests or any other
project space.

The maintainer may edit or remove comments, commits and other contributions that break these rules, and may block
contributors who repeatedly do so. To report behavior that violates this code, use GitHub's
[Report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature or contact the maintainer, [@tunatavsan](https://github.com/tunatavsan).
